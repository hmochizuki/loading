# やさしく待って

画面には、ローディングUIだけがいる。

それは読み込みを示すためのものではなく、短い時間だけそこに現れて、
触れると反応する小さな存在。

タップしたり、なぞったり、押したり、少し待ったりすると、
ローディングは嬉しそうに動いたり、びくっとしたり、眠そうになったりする。

やさしく触れると、落ち着いていく。
焦って連打したり、乱暴になぞったりすると、疲れたり、怖がったりする。

説明はない。誘導もない。成功も失敗もない。
しばらくすると、そのローディングは去っていき、次のローディングが現れる。

「待たされている」のではなく、「一緒に待っている」ような体験。

## 動かし方

ビルドは不要。静的ファイルだけでできている。

```sh
# なにか静的サーバで配信するか
npx serve .

# あるいはそのままブラウザで開く
open index.html
```

スマートフォンでのタッチ操作にも、マウスでのなぞり・クリックにも反応する。

## 登場するローディングたち

- **スピナー** — 回転に沿ってやさしくなぞると気持ちよさそうに回る。逆になぞると戸惑う。連打されると目を回す。押されすぎるとぺちゃんとつぶれる。
- **3つの点** — 点をタップするとその点が跳ねる。リズムよく触れるとそろって楽しそうに跳ねる。連打するとひとつが隠れてしまう。押し続けると困ったように伸びる。
- **プログレスバー** — なぞると進むふりをする。でも完了はしない。強く触られると震え、やさしく押されると呼吸のように満ち引きする。疲れると少し垂れる。
- **スケルトンUI** — なぞると光の帯がついてくる。触れるとぷるっと揺れる。やさしくされると角が丸くなる。乱暴にされると欠けたように揺らぐ。
- **砂時計** — 触れると砂が跳ねる。傾けるようになぞると流れが揺れる。激しく触ると砂が詰まる。疲れると流れが細くなる。

どのローディングも、かまわれないと眠くなり、
去りぎわには、そのときの気分がにじむ。

同じ種類でも、来る子はみんな少しずつちがう。
臆病な子は、なつくまで指から目をそらすように離れる。
人懐こい子は、すぐに頬を染める。
眠がりな子も、からだの大きい子も、せっかちな子もいる。

## つくり

- 依存なしの vanilla JS + Canvas 2D
- `js/heart.js` — こころ。stress / comfort / joy / fatigue / drowsy の5つの値で気分を持ち、生まれつきの性質(臆病さ・人懐こさ・打たれ弱さ・眠がり・元気・大きさ)を個体ごとに持つ
- `js/input.js` — 手つきの感じ取り。タップ・連打・なぞり(速さ)・長押しを見分ける
- `js/loaders.js` — 5種類のローディングと、現れて・生きて・去っていく一生
- `js/main.js` — 舞台。背景の気配と、ローディングの入れ替わり
